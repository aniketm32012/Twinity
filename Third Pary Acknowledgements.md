# 📜 Third-Party Acknowledgements

Twinity Search uses several open-source libraries, frameworks, and APIs to deliver a fast, local web search and AI synthesis ecosystem. We are grateful to the authors and maintainers of these projects.

#### 1. Flask
* **Description:** WSGI web application framework used for backend routing and template rendering.
* **License:** [BSD 3-Clause License](https://github.com/pallets/flask/blob/main/LICENSE.rst)
* **Website:** [palletsreports.com/p/flask](https://flask.palletsprojects.com/)

* **Description:** Flask extension for handling Cross-Origin Resource Sharing (CORS) across search endpoints.

* **Website:** [github.com/corydolphin/flask-cors](https://github.com/corydolphin/flask-cors)

#### 3. Requests
* **Description:** HTTP library for Python used to communicate with external APIs and models.
* **License:** [Apache License 2.0](https://github.com/psf/requests/blob/main/LICENSE)

#### 4. duckduckgo-search
* **Description:** Python library for querying web search results.
* **License:** [MIT License](https://github.com/deedy5/duckduckgo_search/blob/main/LICENSE)
